## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in a web browser
3. **Navigate** through all 8 pages using the navigation menu
4. **Customize** content, images, and contact information as needed

## 🛠️ Customization Guide

### **Content Updates**
- Update personal information in each HTML file
- Replace placeholder contact details with real information
- Add actual project images to the images folder
- Customize service pricing and packages

### **Styling Changes**
- Modify colors in `css/style.css` by updating CSS custom properties
- Adjust spacing, fonts, and layouts as needed
- Add new sections or modify existing ones

### **Adding Images**
- Place images in the `images/` folder
- Update image sources in HTML files
- Ensure images are optimized for web (WebP format recommended)
